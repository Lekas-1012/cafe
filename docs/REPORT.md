## 1. 作品名稱

**Brew by Feel — 手沖咖啡直覺挑戰**

「沒有秤，沒有計時器。你能只憑感覺沖出一杯好咖啡嗎？」

## 2. 創作動機

把以重量與時間為主的手沖流程，轉成需要觀察、直接操作與練習的遊戲。希望玩家關注材料、粉床、類比指針、水流與滴漏，從失敗回饋中建立判斷。

【待填：自己選擇咖啡主題的原因與生活觀察。】

## 3. 遊戲介紹

玩家從六款示範咖啡選豆，設定研磨並轉動手柄，把粉倒入濾杯，再準備熱水。正式手沖時，水流強弱與落點分開控制，並自行安排悶蒸、續注與收尾。結算顯示品質輪廓、風味與可實踐的改進建議。此次增加「失控的手沖」：強流偏移、局部挖坑、桌面累積水灘與可修復的磨豆斷柄，讓失敗更容易看懂，也更有趣。

遊戲不經營店鋪、不購物或累積資源，也不在正式挑戰中顯示注水量、經過秒數或精確水溫。

## 4. 核心功能

1. 六款配方、詳細產地與品種介紹、烘焙篩選。
2. 真正轉動磨豆機、豆粉轉換與連續研磨粗細。
3. 拖移及傾倒粉杯、粉末粒子、粉床累積與鋪平。
4. 開關熱源、類比溫度錶、蒸氣、冷卻及練習模式。
5. 落點與流量解耦，壺身旋轉有幾何補償。
6. 全景、俯視與近看粉床三種觀察角度。
7. 吸收、孔隙水、自由水、排水、溢流與分享壺。
8. 豆款、研磨、粉床、水溫、手沖共同參與評分。
9. 最佳紀錄、重新挑戰、暫停、指南、觸控及鍵盤。
10. 二維落點、慣性、大流量偏流、濾紙與桌面濕痕、局部坑洞。
11. 磨豆暴力判定、斷柄飛落、按住修復；事故實際影響分數與結算評論。
12. 低壺快速撞入杯緣會撞倒濾杯，強撞連帶倒分享壺；液體實際潑出、器具保持倒下，扶正後可接續沖煮。

## 5. 操作方式

研磨時拖曳木質手柄繞中心轉動；倒粉時按住粉杯移到濾杯上方，以滾輪或滑桿傾斜。倒完可晃動濾杯鋪平。熱水階段自行開始及停止加熱，讀類比指針後決定何時沖煮。

手沖時按住水壺前後左右拖移、畫小圈，以滾輪或 W/S 調流量；放開立即停水。大流量與急甩會讓水偏離虛線瞄準環，水柱末端才是實際落點。前後位置也有滑桿／方向鍵。舊式上下拖曳調水模式保留。暴力磨豆斷柄時，按住修復按鈕後可繼續。

## 6. 使用技術

HTML5、CSS3、原生 JavaScript、Canvas 2D、SVG、Pointer Events、Web Audio API、localStorage。測試使用 Python、Playwright 與真實 Chrome，正式網站不需這些開發工具。

純前端、相對資源路徑、無打包、無私人 API 或後端，適合 GitHub Pages。

## 7. AI 協作說明

使用者提出第一階段規格、第二階段完整升級及此次失控手沖需求。Codex 協助檢查舊架構、備份、重構、原創器具繪製、輸入控制、豆款資料、材料模型、流體與評分、瀏覽器測試及文件。

資料核對參考 World Coffee Research 品種目錄。介紹明確區分產地、品種、處理與烘焙；示範配方不冒充真實莊園批次，遊戲風味不宣稱由品種單一決定。

協作過程以實際測試確認功能，而不是把動畫視為已完成物理。詳細歷程見 [DEVELOPMENT.md](./DEVELOPMENT.md)。

## 8. 開發成果

已完成從豆到杯的完整可操作作品。六款合理模型策略測得 91～96 分；正式介面從全部準備到四段手沖的測試取得 **92 分**與平衡風味，並儲存最佳紀錄。

確認三視角共用二維落點、柔和水流精準、大流量有上限偏移，並保留細磨積水、停水排水、溫度萃取與水量守恆。失控相關新增測試見下述現場紀錄。完整測試及限制見 [TESTING.md](./TESTING.md)。

目前是本機可執行且可上傳的狀態，沒有宣稱已公開部署。

此次失控改版也通過確定性模型與 Chrome 操作驗證：暴力拖柄確實斷裂，按住修復後完成所有準備；三視角可前後左右拖壺，沖出濾杯會累積桌面水量。完全沖桌子的模型案例為 0 分；合理四段正式操作仍為 **92 分**。結算新增事故實測紀錄、幽默評論及額外扣分，練習事故扣分為正式的一半。

## 9. 挑戰與解決方法

| 挑戰 | 實際處理 |
| --- | --- |
| 調水流會使落點漂移 | 目標、流量、傾角、壺身、壺嘴分離，逆算補償壺身 |
| 三視角座標一致 | 統一世界與鏡頭換算，共用正規化落點 |
| 豆款不能只是換文字 | 每款溶解性、釋氣、阻力與節奏參數不同 |
| 準備不能是假動畫 | 材料有固定份量，必須實際磨豆與倒粉才可繼續 |
| 水位須連動研磨 | 分開吸收、孔隙水、自由水；依滲透率和水頭排水 |
| 溫度不能隨機猜測 | 類比指針與練習精確溫度，連續冷卻與速率模型 |
| 合理操作應能高分 | 比較正反策略，使用正式介面完成高分測試 |
| 舊功能與紀錄保留 | 保留三視角、暫停、指南、重玩；v1／v2 不刪除，本版 v3 分開記錄 |
| 混亂不能純隨機 | 偏流由流量與時間波形決定、慣性由移動速度決定 |
| 水灘不能無限長物件 | 48 區累積實際外漏與溢水，三視角共用 |
| 斷柄不能卡死 | 停磨保留材料，按住修復再繼續；正常速度安全 |

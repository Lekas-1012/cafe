### 從豆到杯的高分實測

full_brew_test.py 使用正式介面完成：

選豆 → 實際轉柄研磨 → 拖移倒粉 → 鋪平 → 加熱 → 四段注水與悶蒸 → 等待排水 → 自行完成。

以 Playwright 時鐘逐幀推進，沒有改寫遊戲內的材料、準備狀態、萃取或評分。實際測得 **92 分、4 段、沖煮平衡**，並保存正式最佳紀錄。這項測試證明高分策略可以由正式操作達成，不只存在於獨立模型。

- [x] 持壺高速撞進杯緣會撞倒濾杯，猛烈撞擊連帶倒分享壺；一般較輕碰撞只倒濾杯。

- [x] 床內水與分享壺咖啡實際減少，轉為桌面液體，撞倒前後及扶正後水量誤差 <0.000001 ml。
- [x] 倒下時續注與滴漏不會補回分享壺；扶正後可繼續接水，灑出的水保留。
- [x] 點擊真正的扶正按鈕恢復兩件器具，可繼續沖煮並正常結算。

- [x] 暫停時傾倒角度凍結，結束後碰撞與扶正都不再修改成績。
- [x] 此次撞倒完整流程無 JavaScript 例外；實際擷取三視角截圖。

模型案例中一次猛烈撞擊，原有床內水約 44.25 ml、分享壺約 35.95 ml，立即潑出約 68.58 ml，沒有用假水灘取代損失。完整正常四段操作回歸仍取得 **92 分**。實際資料與截圖為 `tests/artifacts/collision-*`。

近看視角在器具落下時會同步拉遠，以免倒下位置被裁切；渲染、壺身及輸入共用此鏡頭換算，扶正後回到近看。實體裝置的碰撞手感仍需人工試玩。
